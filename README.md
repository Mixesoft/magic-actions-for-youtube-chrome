## 🛠️ How to Install in Google Chrome (Developer Mode)

Follow these steps to manually load the official unpacked extension into Chrome:

1. **Download & Unzip:**
   * Download `MagicActions7956.zip` from the **[Releases](../../releases)** section.
   * Right-click the downloaded `.zip` file and extract (unzip) it to a folder on your computer.

2. **Open Chrome Extensions Page:**
   * Open Google Chrome.
   * Type `chrome://extensions/` in the address bar and press **Enter** (or open Menu ➔ **Extensions** ➔ **Manage Extensions**).

3. **Enable Developer Mode:**
   * Turn ON the **Developer mode** toggle switch in the top-right corner of the Extensions page.

4. **Load the Extension:**
   * Click the **Load unpacked** button in the top-left corner.
   * Select the unzipped folder containing the extension files (where `manifest.json` is located).

5. **Verify:**
   * The **Magic Actions for YouTube** card will appear in your list of extensions and the icon will show in your browser toolbar. Open YouTube to confirm the features are active.
